## The line

> I bought a smartwatch to get fit, and now it just watches me get fatter in high definition.

## How it works

`main.py` (Python 3.13) writes that single original sentence to `/output/entry.txt`. It is fully deterministic — no randomness, no network, no input files — so two runs produce byte-identical output.

## Run locally

```sh
python3 main.py
cat /output/entry.txt
```
